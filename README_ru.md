## ✨ Ключевые возможности

| Возможность | Описание |
|------|------|
| 👤 **Настраиваемый отправитель** | Любой номер QQ в качестве отправителя; никнейм получается автоматически или задаётся вручную |
| 🖼️ **Поддержка изображений** | К сообщению можно прикрепить изображения; по позиции они автоматически распределяются по соответствующим репликам |
| 📢 **Поддержка @упоминаний** | `@QQ号` в тексте автоматически преобразуется в @упоминание |
| ⏰ **Подделка времени** | Своё время отправки для каждого сообщения (метки времени Unix с точностью до секунды) |
| 🏷️ **Подделка внешней карточки** | Своё название внешней карточки объединённой пересылки |
| 🤖 **Инструмент для LLM** | ИИ может напрямую вызывать его для генерации объединённой пересылки |
| 📨 **Группы и личные чаты** | Тип чата определяется автоматически при отправке |

## 📖 Обзор функций

### 伪造消息 (поддельное сообщение)

Команда `/伪造消息` генерирует объединённую пересылку в формате `QQ号|内容 \| QQ号|昵称|内容`:

```
/伪造消息 123456|你好 \| 654321|小王|你也好
```

| Символ | Назначение |
|------|------|
| <code>&#92;&#124;</code> | Разделяет разные реплики (сегменты) |
| <code>&#124;</code> | Внутри сегмента разделяет QQ / никнейм / содержимое |

**Возможности вкратце**

| Возможность | Запись | Описание |
|------|------|------|
| Автоникнейм | `123456\|内容` | Настоящий никнейм автоматически получается через API |
| Свой никнейм | `123456\|老王\|内容` | Принудительно использует указанный никнейм |
| @упоминание | `123456\|@789012 说得对` | Упоминает других участников в тексте |
| Изображение | `123456\|看看这个`, затем отправить картинку | Изображение по позиции прикрепляется к соответствующему сегменту |

### 伪造外表 (внешняя карточка)

Команда `/伪造外表` задаёт своё название внешней карточки объединённой пересылки:

```
/伪造外表 123456|小明|我喜欢你 \| 654321|小红|我也喜欢你 \\| 私密对话
```

Снаружи отображается 「私密对话」 (приватная переписка), а внутри — переписка между 小明 (Сяомин) и 小红 (Сяохун).

## 🚀 Быстрый старт

### Предварительные требования

- ✅ AstrBot ≥ v4
- ✅ Запущенный NapCat (обмен идёт через встроенный в AstrBot адаптер aiocqhttp, дополнительные порты не нужны)

### Шаг 1: установка

**Способ 1: маркет плагинов**
- AstrBot WebUI → Маркет плагинов → поиск `fakesession_assistant`

**Способ 2: ручная установка**
- Поместите папку плагина в `/AstrBot/data/plugins/`
- Перезагрузите плагин

### Шаг 2: использование

- Отправьте в чат `/伪造消息 QQ号|内容 \| QQ号|昵称|内容`
- Или просто попросите ИИ сгенерировать её, вызвав инструмент `create_forward`

## 🛠️ Инструмент, вызываемый LLM

Плагин регистрирует 1 инструмент для LLM; модель сама определяет, когда его вызвать, — достаточно описать запрос обычным языком:

```
用户: 帮我伪造一段我和小明的聊天记录，我说"明天见"，小明说"好的"
🤖 → create_forward(params={"segments":[{"qq":"123456","text":"明天见"},{"qq":"654321","nickname":"小明","text":"好的"}]})
    已发送合并转发（2 条消息）✅
```

### create_forward

Создаёт сообщение объединённой пересылки для подделки переписки.

| Параметр | Обязательно | Описание |
|:----|:----:|:-----|
| `params` | ✅ | JSON-строка, формат см. ниже |

**Формат JSON для params**

```json
{
  "segments": [
    {"qq": "123456", "text": "你好", "nickname": "老王", "time": 1756684800, "image": "url"}
  ],
  "title": "可选的外层标题"
}
```

| Поле | Обязательно | Описание |
|------|:----:|------|
| `qq` | ✅ | Номер QQ (5-12 цифр) |
| `text` | ✅ | Текст сообщения |
| `nickname` | Рекомендуется | Никнейм; если не указан, скорее всего будет показан номер QQ |
| `time` | Необязательно | Метка времени Unix с точностью до секунды, используется для подделки времени сообщения |
| `image` | Необязательно | URL изображения (можно также просто отправить картинку — она автоматически прикрепится к последнему сегменту) |

> 💡 Поддерживаются два стиля передачи параметров: `{"segments": [...]}` или массив `[...]`, переданный напрямую.

## ⚠️ Часто задаваемые вопросы

### Q1: Нужно ли что-то настраивать?

Команды работают практически без какой-либо настройки.

### Q2: Откуда берутся никнеймы?

Сначала настоящий никнейм запрашивается через адаптер OneBot; если запрос не удался, отображается как «QQ+номер». Также можно вручную указать никнейм в формате, чтобы переопределить его.

### Q3: Какие платформы поддерживаются?

Адаптер OneBot на основе NapCat (aiocqhttp); поддерживаются групповые и личные чаты QQ.

### Q4: Законна ли подделка переписки?

Плагин предназначен только для законных демонстраций и творчества. **Категорически запрещено** использовать его в противоправных целях, таких как мошенничество, клевета, фальсификация доказательств; всю ответственность за использование несёт сам пользователь.
